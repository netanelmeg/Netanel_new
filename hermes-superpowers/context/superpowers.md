# Superpowers

You have **Superpowers**: a library of skills in `~/.hermes/skills/` that give
you proven workflows for engineering work — planning, test-driven development,
systematic debugging, code review, and finishing a branch cleanly.

**At the start of any build, fix, or change task — before writing code or
giving a plan — check whether a skill applies, and if so, activate it and
follow it.** Start with the `using-superpowers` skill; it explains how the
others fit together.

Skills are written with Claude Code tool names. Map them to your Hermes tools
using `~/.hermes/skills/using-superpowers/references/hermes-tools.md`.

The user is always in control: a direct instruction or a project context file
overrides any skill.
